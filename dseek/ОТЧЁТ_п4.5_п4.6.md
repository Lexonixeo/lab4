# Обработка данных: п4.5 и п4.6

Лабораторная работа «Скорость звука в газовой среде».
Условия опыта (`data/conditions.txt`): **t = 24,7 °C**, относительная влажность **43,5 %**.
Расстояние между микрофонами **L = 1,158 м**, шаг отсчётов **4 мкс** (250 кГц), микрофон 1 измеряется на 2 мкс позже микрофона 0.

Всё считается скриптом `soundProcessing.py` (запуск из корня: `python3 soundProcessing.py`), самопроверка формул — `python3 soundFunctions.py`.

## п4.5. Аналитическая модель скорости звука

### Функции

* `h2oFraction(temperature, rh)` — мольная доля паров воды: давление насыщенных паров по таблице (`np.interp`) умножается на относительную влажность, делится на атмосферное давление.
* `speedOfSound(temperature, h2oX, co2Max)` — скорость звука $c=\sqrt{\gamma RT/M}$ для смеси «N₂ + O₂ + Ar + CO₂ + H₂O»:
  CO₂ замещает кислород ($x_{O_2}+x_{CO_2}=\mathrm{X}_{O_2}$), пары воды разбавляют остальные газы в $1-h_{2o}X$ раз;
  молярная масса — сумма по компонентам, теплоёмкости — $C_v=\frac{1}{2}R\sum i_k x_k$, $\gamma=C_p/C_v$.

### Проверка формул (пункт «Как проверить»)

| Проверка | Расчёт | Ожидается |
| --- | --- | --- |
| Сухой воздух, 20 °C, без CO₂ | **343,45 м/с** | ~343,4 |
| 21,9 °C, влажность 34 %, без CO₂ | **345,04 м/с** | ~345,0 |
| Наклон по CO₂ | **−0,81 м/с на 1 %** | ~−0,8 |
| Переход влажности 34 % → 100 % | **+0,95 м/с** | ~+1,0 |
| `h2oFraction(21.9, 34)` | 0,00882 | ~0,0088 |
| `h2oFraction(21.9, 100)` | 0,02593 | ~0,026 |

Все проверки сходятся.

## п4.6. Концентрация углекислого газа

### 1. Задержка найдена программой (+1 балл)

Ручная отметка мышью заменена алгоритмом (шаги из т4.4):

1. вычесть фон по первым 200 отсчётам;
2. сгладить скользящим средним (шум АЦП ~2 кода, амплитуда импульса ~100 кодов);
3. найти начало импульса микрофона 0 (6 шумов над фоном);
4. перебирать сдвиг **N** второго сигнала и искать максимум коэффициента корреляции участка начала импульса; на каждом сдвиге из обоих окон снимается линейный тренд (у каналов разный наклон фона);
5. уточнить вершину параболой по трём точкам — получаются доли отсчёта;
6. результат — медиана по сетке параметров окна, разброс по сетке — оценка устойчивости.

Задержка:  **τ = N · 4 мкс + 2 мкс**.

Контроль алгоритма на примере из методички (`air1`, `breath1`): получено **N = 835** и **N = 842**, то есть ровно те значения, что указаны в методичке.

### Оценка точности

Наклон прямой −1,25 %/(м/с), то есть 1 % CO₂ ≈ 0,8 м/с.

| Источник | Δτ, мс | Δc, м/с | ΔCO₂, % |
| --- | --- | --- | --- |
| один отсчёт АЦП | 0,0040 | 0,42 | 0,52 |
| среднее по опытам (SEM) | 0,0045 | 0,47 | 0,59 |
| разброс по записям (1σ) | 0,0111 | 1,15 | 1,44 |
| расстояние L ± 2 мм | — | 0,60 | 0,75 |
| температура ± 0,5 °C | — | 0,30 | 0,38 |

Отдельно по разности «выдох − воздух»: Δτ = 0,0414 мс, Δc = 4,2 м/с. Ошибки расстояния L и температуры при вычитании почти сокращаются, поэтому доля CO₂ в выдохе по разности скоростей получается **5,3 ± 0,6 %**.

### Доля усвоенного кислорода (контрольный вопрос 6)

По модели т4.3 каждая усвоенная молекула O₂ даёт одну молекулу CO₂, поэтому по приросту CO₂ в выдохе находят, какая часть вдохнутого кислорода усвоена:

$$\eta=\frac{c_{\mathrm{CO_2}}^{\text{выдох}}-0{,}0003}{0{,}2095}$$

Здесь 0,0003 — доля CO₂ во вдыхаемом воздухе, 0,2095 — доля кислорода в нём.

Проверка формулы по примеру из методички: при 4 % CO₂ получается η = (0,04 − 0,0003)/0,2095 = **0,189 ≈ 19 %**, как и указано в т4.3.

Для наших измерений:

| Вариант | CO₂ в выдохе, % | η, % |
| --- | --- | --- |
| по прямой для влажности 100 % | 6,84 | **32,5 ± 1,4** |
| по разности скоростей | 5,3 | **25,2 ± 3,2** |
| по прямой с поправкой на сдвиг метода | 6,5 | 30,9 ± 3,2 |

Физиологическая норма — **20–25 %**: организм усваивает примерно пятую часть вдохнутого кислорода, дыхательный коэффициент около 0,8 (на одну молекулу O₂ приходится около 0,8 молекулы CO₂). Это соответствует 4–5 % CO₂ в выдохе.

Наше значение по разности скоростей (25 %) попадает в норму, по абсолютной скорости (32 %) — завышено. Причина та же, что обсуждалась выше: абсолютная скорость опирается на L и T и на формулу влажности 100 %, а разность скоростей от них свободна. Поэтому для η честнее брать **25 ± 3 %** и отметить, что завышение по второму варианту объясняется систематикой метода, а не физиологией.

### Что обсудить в отчёте

* Доля CO₂ в атмосферном воздухе (0,04 %) этим методом **не различима**: результат 0,2 % при погрешности ±1,4 % — это ноль в пределах ошибки. Так и должно быть.
* В выдохе CO₂ различим уверенно: несколько процентов.
* Два числа для выдоха (6,8 % по прямой и 5,3 % по разности скоростей) отличаются потому, что первое использует абсолютную скорость и прямую для влажности 100 %, а второе — только разность скоростей и наклон. Разность надёжнее: она нечувствительна к L и T. Реальное значение лежит между ними, в пределах 5–7 %.
* Запись `AIR12hlopclosed` снята с закрытой заглушкой; её задержка (3,341 мс) совпадает с остальными, поэтому в среднее включена.

### Почему остальные записи не дают более точного результата

В папке есть ещё записи `sig400hz`, `sig440hz1`, `sig440hz2`, `sig500hz`, `kostya155pm5hz`, `kostya155pm5hz2`, `krik1` и `bad_old_data/AIR1…6`. На них рассчитывали получить более точную скорость звука, но по существу это другой опыт, и вот почему.

**1. Это непрерывные тоны, а не хлопок.** Доля времени, где огибающая выше четверти пика, у них 0,6–1,0 против 0,3–0,5 у хлопков. Импульса с фронтом нет, а значит нет и точки «приход сигнала», по которой в п4.6 меряют задержку.

**2. В трубе тон даёт стоячую волну.** Для бегущей волны фазы каналов связаны как φ₁ − φ₀ = −2πfτ и τ = L/c. У стоячей волны фазы определяются положением узлов и пучностей, то есть геометрией трубы, а не временем пролёта. Измерения это подтверждают: на основном тоне разность фаз у `sig440hz1` и `sig440hz2` равна 0,995π и 0,968π, у `sig500hz` −0,84π, а амплитуды каналов различаются в 1,5–2,9 раза. Набор «фаза около 0 или π плюс сильно разные амплитуды» — характерная картина стоячей волны, а не бегущей.

**3. Задержка по тону неоднозначна.** Период 440 Гц равен 2,28 мс, а ожидаемая задержка — 3,36 мс, то есть больше периода. Кросс-корреляция `sig440hz1` даёт два почти равных максимума: 0,988 при τ = 1,154 мс и 0,985 при τ = 3,418 мс. Первый отвечает 1003 м/с, второй — 339 м/с. Выбрать между ними по самим данным нельзя — это неоднозначность фазы. У `sig400hz` вдобавок низкая корреляция (0,54), у `sig500hz` сигнал слабый (0,65).

**4. В записях есть постоянная помеха около 25 кГц** (наводка АЦП). Она не связана с хлопком: уровень до импульса и после одинаков (1,49 против 1,50 у `AIR7hlop`). Помеха слабая, около 3 % мощности, поэтому её не фильтруем: проверка показала, что фильтрация только расширяет фронт и увеличивает разброс задержек на порядок (σ растёт с 0,016 до 0,20 мс).

**5. `bad_old_data/AIR1…6` сняты на другой установке** — другой постоянный уровень и другое поведение фона, к текущей серии они не относятся.

Итог: более точную скорость звука по этим записям получить нельзя — причина не в обработке, а в физике опыта. Точность в п4.6 ограничена уже не алгоритмом, а разбросом между хлопками (σ = 0,011 мс, меньше трёх отсчётов АЦП).
